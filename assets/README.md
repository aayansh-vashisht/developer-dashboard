# Developer Learning Dashboard

A client-side developer productivity dashboard designed to track software engineering tasks, algorithmic problem-solving milestones, and deep-work study hours. Built entirely with semantic HTML5, responsive CSS Grid/Flexbox, and vanilla JavaScript without external framework dependencies.
